# BRUNO — principios de dirección

- **Stupid Simple** para usuario, frontend y backend.
- No perder ni corromper trabajo; después velocidad, confiabilidad y simplicidad.
- Los flujos centrales: encontrar/escuchar/descargar y subir/organizar/editar.
- Elegir el problema importante, demostrarlo y cerrarlo limpio.
- No conservar complejidad por trabajo invertido ni borrar contratos sin identificar dependencias.
- Un build verde, test aislado o informe histórico no certifica producción.
- La visión V1 permanece; el desarrollo activo ahora es Web + Cloud.
- Desktop/Tauri está pausado, no eliminado.
- La IA ayuda a decidir e implementar; las decisiones sensibles y acciones productivas requieren autorización.
