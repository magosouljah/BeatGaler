# Emil Kowalski — skills de diseño para BeatGaler

Esta carpeta contiene 12 skills de **diseño e ingeniería de interfaces Web**. Los agentes compatibles con el estándar de skills por proyecto pueden consultar cada `SKILL.md`.

**Uso orientativo:** `apple-design` y `emil-design-eng` para calidad de UI; `animate`, `review-animations`, `animation-performance`, `improve-animations`, `find-animation-opportunities` y `animation-vocabulary` para movimiento y físicas; `prototype` para comparar variantes; `break-ui` y `mobile-native` para robustez/responsive; `pick-ui-library` para soluciones mantenibles.

**Límites:** son pautas externas, no código productivo. Las decisiones de BeatGaler y el código actual prevalecen. El laboratorio sigue aislado de `src/` y de producción. Revisar antes de aplicar recomendaciones que cambien arquitectura, seguridad o accesibilidad. No hay dependencia de ejecución ni conexión de red añadida por estos archivos.

El repositorio original también contiene skills para Swift, Expo y Sonner; no se incluyeron porque no corresponden a Web + Design Lab. Para actualizar, comparar con upstream y mantener licencia y atribución.
