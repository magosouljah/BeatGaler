## Corrections after reviewing PR #86

### Withdrawn P2 — “SBOM absent”

Withdrawn. The live release workflow now runs `npm sbom --sbom-format spdx`, validates the document, copies `sbom.spdx.json` into release assets and includes it in the final SHA256SUMS set. The old-baseline observation must not be reported as an open finding.

### Provenance finding narrowed

The live release workflow now:
- binds Windows/macOS build run IDs to the same source SHA;
- checks out release tooling at that verified source SHA;
- creates immutable draft-before-publish assets;
- emits machine-readable `provenance.json` plus per-platform runtime provenance;
- includes checksums and SBOM.

Residual P2 is only that this metadata is not itself a cryptographically signed workload-identity/SLSA-style attestation. This is pre-GA hardening/traceability, not a claim that provenance is absent.
