# Motion Graphics — referencias para marketing de BeatGaler

**Estado:** referencias documentadas. Los MP4 originales fueron aportados en conversación para análisis interno; se prepararon en un paquete aparte para subirlos, no están todavía incluidos en este commit.

**Objetivo:** estudiar animación tipográfica, transiciones, movimiento de interfaces, timing y sincronía con audio para el primer video promocional de BeatGaler. No son plantillas a copiar ni aprobación de un storyboard.

**Alcance:** solo carpeta de referencias en `design/beatgaler-design-system-lab-v1`. No tocar `main`, producción, Cloud ni componentes activos.
